Eclipse è un ambiente di sviluppo integrato multi-linguaggio e multipiattaforma che utilizzeremo per sviluppare i nostri programmi in Java. I programmi che abbiamo scritto verranno compilati dalla JDK che abbiamo installato in precedenza.

## Creare un progetto Java
Un progetto Java sarebbe un directory per il nostro programma che inserisce la *JRE System Library* e una cartella *src* che sarà il cuore del nostro programma. Per creare un progetto Java bisogna andare in:

> *File >> New >> Java Project*

Si aprirà una finestra dove dovremo inserire il nome del progetto, il resto lo lasceremo invariato. Premiamo *Next* e cacciamo la spunta a *Create module-info.java file* e poi cliccheremo su *Finish*.

## Creare una classe
Una classe sarebbe il file in cui andremo a scrivere il programma per poi eseguirlo. Per crearlo, dobbiamo posizionarci nella cartella *src* facendo:

> tasto destro del mouse *>> New >> Class*

Si aprirà una finestra dove dovremo inserire il nome della classe, il resto lo lasceremo invariato (c'è anche la possibilità di inserire in automatico anche il *main*).
