## Programma del corso
Il programma del corso si divide in tre categorie principali:
- **fondamenti del web e UI:** i mattoni fondamentali per la costruzione di applicazioni web, partendo dall'[[3.3 Architettura|architettura]] fino alla presentazione. Avremo:
	- [[1.1 Anatomia di un sistema informativo sul Web|anatomia di un sistema informativo sul Web]] e [[1.2 Protocollo HTTP|protocollo HTTP]];
	- [[2.1 HTML|HTML]] e CSS;
	- [[2.3 Layout della pagina|layout della pagina]] e framework ([[2.4 Bootstrap|Bootstrap]]).
- **client-side programming:** approfondimento sulla logica di esecuzione all'interno del browser per rendere le pagine interattive. Avremo:
	- [[3.1 JavaScript|JavaScript]], [[2.4 Eventi|Eventi]] e il DOM;
	- programmazione asincrona con [[3.5 Ajax|Ajax]] e [[3.4 jQuery|jQuery]];
	- JSONP e richieste cross-domain.
- **server-side Java web:** tecnologie per lo sviluppo della logica di business e della persistenza dei dati sul server. Avremo:
	- [[4.1 Java Servlet|Java Servlet]] e JSP (JavaServer Pages);
	- JSTL e [[4.4 Expression Language|Expression Language]];
	- pattern MVC e persistenza con JDBC.

## Obiettivi del corso
Gli **obiettivi** del corso sono:
- comprendere l'[[3.3 Architettura|architettura]] dei sistemi informativi basati sul Web;
- acquisire competenze nella progettazione e sviluppo di interfacce utente moderne;
- padroneggiare la programmazione lato client per l'interattività avanzata;
- apprendere lo sviluppo di applicazioni web dinamiche lato server utilizzando tecnologie Java;
- capacità di integrare [[0.00 Basi di Dati|basi di dati]] in applicazioni web seguendo pattern architetturali standard.
